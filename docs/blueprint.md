# **App Name**: Kidney Diet Tracker

## Core Features:

- Meal Logging: Log meals by searching for food items and specifying quantities. Meals are plain text stored using the browser's local storage.
- Nutrient Calculation: Automatically calculate and display the calories, protein, sodium, potassium, and phosphorus for each logged meal.
- Daily Summary: Display a dashboard summarizing the daily intake of calories, protein, sodium, potassium, and phosphorus.
- Searchable Food Database: Enable users to search a built-in food database for detailed nutrient information. Use a tool, perhaps one provided by a third party via API or downloaded as structured data, to respond to specific questions about nutrient values.

## Style Guidelines:

- Primary color: Soft green (#A7D9A9) to evoke calmness and health.
- Background color: Light beige (#F5F5DC) for a clean and gentle feel.
- Accent color: Pale olive (#B8BDB4) to complement the primary color without overwhelming.
- Body and headline font: 'PT Sans', a humanist sans-serif that balances modernity and warmth, suitable for both headlines and body text.
- Use simple, outlined icons to represent nutrients and food groups. All icons must be monochrome (the same soft green as used in the primary color).
- Design a clean and intuitive layout with a focus on readability and easy navigation. Provide an easily read dashboard summary.
- Use subtle transitions and animations to provide feedback on user interactions.
